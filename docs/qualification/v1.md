# Frozen qualification v1

Written before any Minuta model output. Do not change prompts, fixture text,
thresholds or model versions in response to these outcomes. Preserve failures;
corrections need a new named protocol/cohort. Implementation/observer repairs
must retain the original run and identify the change.

## Scope and controls

One temporary free public Ubuntu job (20 minutes) generates the actual npm lock,
runs focused source/core checks and a static production build. It operates on a
tracked-file copy in nonce/inode-owned scratch. Preserve every command's complete
outer streams, source hashes, lock, build file manifest and cleanup receipt;
exclude dependencies, dist binaries and model caches from artifacts.

After exact-source Vercel READY, one temporary free public macOS job (20 minutes)
uses pinned Playwright 1.56.1 Chromium against that anonymous public URL. No auth,
paid API, real recording or private data. Native macOS `say` renders exactly the
two texts in tests/fixtures/speech.json. Choose the first installed voice in
catalog order for its declared locale, before running any model, with no
post-output selection. `afconvert` makes PCM16 mono 16 kHz WAV. Preserve the
catalog, chosen voices, fixture hashes and WAV before model execution.

Tests use the real published worker and real pinned public weights from
models-v1.json. No mocked model, network response replacement, golden transcript
injection or remote inference is allowed. Record browser/runtime versions,
deployment source and actual asset bodies/hashes; model ONNX cache bodies are
hashed inside the browser one at a time, retaining only size/digest in results.
Keep authored WAVs, output text, notes JSON/Markdown/native audio downloads,
screenshots, observed network method/body summaries and teardown. This fixture
cohort is two synthetic utterances; it is neither a holdout nor a statistical
claim about real meeting quality.

## Predeclared acceptance

- C01–C24: core/schema/audio tests use existing Node without dependencies locally.
  Exact cases are tests/unit/core.test.mjs; all must pass.
- B01 notebook: explicit save, reload via library, literal text export/import
  with fresh ID, cancellation preserving the open draft, two-tab revision
  conflict preserving the newer record and stale draft, two-step deletion
  preserving the open copy. Native downloaded JSON excludes audio.
- B02 narrow: 390 px and 320 px horizontal fit, touch-accessible editor and
  downloads, explicit keyboard tabs, no uncaught page error.
- B03 failure/recovery: malformed WAV/JSON keep the current data; corrupted
  record is not overwritten; raw metadata can be downloaded. A disposable
  quota/storage rejection leaves the working copy. This is browser failure
  handling, not an assertion about every device's storage behavior.
- B04 capture: fake microphone uses the frozen authored English WAV through
  native Chromium getUserMedia and the actual AudioWorklet. Downloaded recording
  is valid PCM16, non-silent and at least 1 second; stop leaves every observed
  track ended and context closed. No physical microphone/tab/system-audio proof.
- M01/M02: each frozen imported WAV transcribes through the real worker in its
  declared language. Normalize lowercase/NFD accents/punctuation to words;
  Levenshtein word error rate <=0.35 independently for English and Spanish.
  Proposals are explicitly reviewed/applied and exported. Report actual WER,
  duration and raw text; no quality claim beyond these two fixtures.
- M03: real Qwen draft of the English result. While it runs, change personal
  notes. Proposal must be nonempty, <=24,000 characters and contain `Ana` and
  `Friday` case-insensitively. This tiny lexical sanity gate does not establish
  factuality. Apply must be disabled; saving a separate copy must preserve
  current edits and the captured input. Inspect actual draft manually for
  invented owners/dates or lost price uncertainty; report issues honestly.
- M04: one actual Qwen Spanish draft, nonempty, <=24,000 characters containing
  `Ana` and `viernes`. Explicit apply/save/export. Again, lexical sanity is
  not semantic accuracy. Model byte digests must match pinned metadata, and
  all actual model resolve requests must use the declared revision.
- Network: application/text/audio upload requests must be absent. Only static
  app/runtime fetches and model/tokenizer download GET/HEAD requests are allowed.
  Browser permission, unsupported audio, model cache/download failure, cancellation
  and general real-meeting quality remain separately scoped limits.

Do not rerun a green cohort just for activity. A failed implementation/observer
must be repaired concretely and rechecked only for its affected boundary.
